# VIG-05-05: Явные таймауты upstream-клиента

**Статус:** Ready for implementation
**Epic:** [EPIC-05](../../epics/epic_05_v0_hardening.md)
**Ветка:** Надёжность proxy > явные таймауты upstream-клиента
**Зависит от:** нет
**Предпочтительный порядок (не блокировка):** после issue стабильных proxy-ошибок - истекший таймаут должен отображаться стабильной proxy-ошибкой
**Блокирует:** нет
**Оценка:** 1-2 инженерных дня
**Уверенность:** High

## Результат

Upstream `WebClient` сконфигурирован явными таймаутами (connect, write,
response) и настройками pooling, задаваемыми через конфигурацию (env/file) с
дефолтами, безопасными для длинных LLM-стримов. Сейчас используется
`WebClient.of()` с библиотечными дефолтами.

## Требования

Раздел «Входит в v0»: connection pooling, backpressure, timeout и cancellation
propagation.

## Критерии готовности

- [ ] Настройки таймаутов подключены к существующему механизму конфигурации
  (`env > file > defaults`, префикс `VIGILANT_`), включая дефолты.
- [ ] Response timeout не убивает легитимный длинный стрим: принятая модель
  (рекомендованный baseline: idle-based timeout либо явный большой response
  timeout для стримов) зафиксирована и протестирована.
- [ ] Истекший таймаут отображается клиенту стабильной proxy-ошибкой из
  VIG-05-01.
- [ ] E2E-тест: зависший upstream прерывается по таймауту с малым тестовым
  значением, настроенным через env.
- [ ] Unit-тесты загрузки и валидации новых параметров (отрицательные,
  нулевые, невалидные значения).
- [ ] Дефолты и названия параметров задокументированы в
  `vigilant.conf.example` и README.
- [ ] `./gradlew build` проходит.

## Не входит

Retry, circuit breaker, per-route таймауты, таймауты plugin-вызовов.

## Рекомендуемые решения внутри issue

- Названия: `vigilant.upstream.connect-timeout`, `write-timeout`,
  `response-timeout` (env: `VIGILANT_UPSTREAM_CONNECT_TIMEOUT` и т.д.).
- Модель для стримов: response timeout как время до первого байта плюс
  idle-таймаут между чанками, если Armeria поддерживает; иначе документально
  большой response timeout с явной оговоркой.
