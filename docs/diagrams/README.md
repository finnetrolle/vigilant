# UML-диаграммы

Этот каталог содержит исходники архитектурных схем в формате PlantUML.
Диаграммы компонентов, последовательностей, состояний и деятельности используют
нотацию UML 2.0. Исходник `.puml` является доступным для ревью источником
истины; сгенерированные SVG- и PNG-файлы в Git не хранятся.

Основные диаграммы:

- [runtime-components.puml](runtime-components.puml) - компоненты текущей
  исполняемой системы и внешние границы;
- [request-inspection-sequence.puml](request-inspection-sequence.puml) -
  последовательность обработки поддержанного запроса;
- [policy-selection-activity.puml](policy-selection-activity.puml) -
  сопоставление, переопределения и вычисление неизменяемого снимка политик;
- [tracing-sequence.puml](tracing-sequence.puml) - происхождение трасс и
  сегментов W3C.

Локальное построение при установленном PlantUML:

```bash
plantuml docs/diagrams/*.puml
```

Предварительный просмотр в IDE должен использовать PlantUML без подмены связей
на Mermaid или неформальные стрелки блок-схем. Изменение поведения сначала
фиксируется в нормативном `spec/`, затем отражается в соответствующей
UML-диаграмме и текстовом документе.
